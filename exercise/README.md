## Introduction
In this lab, you'll build an app that will store a list of people, a list of languages and also and the languages that the people know. You are to create and app that would create, read, update and delete (CRUD) the data from the API provided.

## Design
You are to come up with the design. The look and feel of the app will be up to your imagination. You may use as many or 1 component, as you see fit.

## Requirements
As you have been given the API dictionary for the app.

The app would be able to:
- Retrieve all languages
- Delete a language
- Add a language
- Retrieve all people
- Add a **new** person
- Delete a person
- Update a person
- Retrieve all languages a user knows
- Delete a language a user knows
- Add a **new** language for a particular user

## More Details
You need not use all the APIs provided as long at the requirements above are fulfilled.

You can use any hooks, methods, libraries, etc. whether they have been taught in class or not.

## Functionality
The app will call the APIs provided to perform CRUD functions.

## Main Objective
In this lab, you will learn how to read a requirements specification and develop an app to meet the requirements with only the APIs provided.
